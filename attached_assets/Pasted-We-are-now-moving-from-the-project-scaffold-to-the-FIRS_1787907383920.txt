==================================================
CORE API
==================================================

Implement:

POST /api/analyze

Request:

{
  "text": "user supplied text"
}

Response:

{
  "simpleExplanation": "string",
  "keyPoints": ["string"],
  "steps": ["string"],
  "difficultWords": [
    {
      "word": "string",
      "meaning": "string"
    }
  ]
}

The backend should validate that text exists and is not empty.

Return useful HTTP error responses if the request is invalid or the AI request fails.

Do not expose the API key or internal error details to the client.

==================================================
AI PROMPT DESIGN
==================================================

Create a dedicated backend service for the communication transformation.

Do NOT put the large AI prompt inside an Express route.

The AI should be instructed that:

You are an accessibility-focused communication assistant.

Your task is NOT to change the meaning of the user's information.

Transform complex information into clearer and more accessible language.

Rules:

- Preserve the original meaning.
- Do not invent facts.
- Do not remove important conditions, warnings, dates, numbers, or requirements.
- Use simple, natural language.
- Prefer short sentences.
- Avoid unnecessary jargon.
- Explain unavoidable technical/legal/academic terminology.
- Make the result easy to scan.
- Do not assume the user has a disability.
- Do not diagnose or classify the user.
- Do not give medical/legal/etc. advice beyond what is present in the source.
- If the source is ambiguous, preserve the ambiguity rather than inventing an interpretation.

Return ONLY structured JSON matching the required schema.

==================================================
IMPORTANT: PRESERVE INFORMATION
==================================================

This is NOT a generic summarizer.

For example, if the source says:

"Applicants must submit the required documents no later than 30 September. Applications received after this date will not be considered."

The AI must preserve:

- required documents
- deadline
- 30 September
- consequence of missing the deadline

It must not simplify away important information.
